Catches the subject that is the diff's table of contents: `Update handlers.go and router.go`, `Edits across internal/billing`, `Bump the constant in limits.go`. It reads the first line only, because that is the line a log, a list of pull requests and a release note carry on their own, so a body that goes on to explain everything does not rescue it. Naming a symbol is not itself the fault: `Take a context on store.Put so a shutdown can cancel a write` names a function and still says what is different, and passes. It judges commit subjects and pull request titles alike, so a config that wants it for commits names it under `rules:` with `kind: [commit]`.
