Catches the type assertion, cast or pointer reinterpretation that nobody has justified: the bare one, and the one whose comment declares it safe without saying what makes it so. anti-slop's oxlint rule already does the presence check, that every non-const assertion has a non-empty comment near it, which is the half an AST can settle; this rule judges the substance, whether the sentence names an invariant a reader can check or only asserts that the author was sure.
