Catches the description that never reaches the question of undoing the change, and the two ways a Merge Danger section answers it without answering: the bare label, `One-way door.` with nothing after it, and the label propped on itself, two-way because we can walk it back. A time or a condition hung on the end of such a label does not rescue it, because it names neither the thing that has gone out nor what would have to be wrong. The rule reads the ground, not the vocabulary: a description that never says one-way or two-way but says a revert is the whole of it because nothing outside the process was touched has stated the door. What it cannot do is check the claim. A change can be called a two-way door and not be one, and only the code settles that; this rule asks that somebody thought about it and wrote down what they weighed.
