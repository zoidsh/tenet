Catches a comment written to the person who asked for the change rather than to the next reader of the file: one that cites the request, the instructions or a discussion, or that explains the code by what the previous version or a first attempt did. vitest's AGENTS.md says the same thing from the other side, "You MUST NOT add a code comment that only justifies the change against a prior implementation." A static linter can only count comments or match a phrase list, and a phrase list convicts the honest historical note; this rule reads whether the sentence is about the code as it stands or about how it got here.
