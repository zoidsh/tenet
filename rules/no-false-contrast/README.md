Catches the sentence that invents a smaller claim so it can be corrected: the pipeline that is "not just a list of steps", the index rebuild that is "not merely an optimisation". The regex-grade neighbour is the phrase itself, `not (just|merely|simply|only) .*,? but`, which a `grep -nE` finds in a pre-commit hook; what grep cannot tell is which of those sentences is a real distinction, so it flags the negation that names what a command genuinely does not do along with the straw man, and this rule is the half that separates them.
