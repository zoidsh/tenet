Catches the colon used as a hinge rather than as an introduction: the cause, the fix, the one thing that matters, each announced and then delivered. The regex-grade neighbour is the frequency cap, a `grep -c ':'` per paragraph or a Vale rule on punctuation density, which says how many colons a page has; it cannot say which of them stands before a list or a code block, where a colon belongs, and which stands between a noun phrase and its punchline, which is the only one this rule reports.
