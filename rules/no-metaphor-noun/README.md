Catches the config file described as a substrate and the release that moves along a vector, and leaves the vector that is an ordered tuple alone. The regex-grade neighbour is the word list itself, `grep -inwE 'substrate|wedge|vector|locus|flywheel|bedrock'` or the same words in a Vale vocabulary, which is where the list belongs if every use is to be flagged; a project whose documentation talks about embeddings, sensors or chromosomes cannot run that grep at all, and telling the literal use from the borrowed one is the only thing this rule does.
