Catches the Evidence section that asserts the checking happened rather than showing what came out of it: tested locally, CI is green, tests added for both cases, coverage up four points. It also catches evidence given from one side, the response the endpoint now returns or the screenshot of how the page now looks, because a single state would read the same in a tree where the work was never done; what the rule wants is two of them, a benchmark either side, an error and its absence, or steps written out so somebody else could take them. The regex-grade neighbour is the empty section, an `## Evidence` heading with nothing under it, which `grep -A2` settles. What no lint can do is tell whether the run happened: a pasted test run and an invented one read the same, so this asks that the steps and the outcomes are on the page, never that anybody executed them. It ships under the `standalone` tag: it reads usable at 0.93, its two one-sided cases, a quoted response and a captured screen with nothing beside either, sitting at 0.77 to 0.82 with one or the other under the cutoff on any given run. Some of its criteria, the coverage figure and the paired screens among them, still rest on a single example each, so the wording runs further ahead of the evidence than a preset rule's should; it waits for a wider corpus.
