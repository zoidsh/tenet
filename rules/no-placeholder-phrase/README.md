Catches the stub that presents itself as done: a comment excusing the code below it as temporary or partial, a description of what the real version would do, or a deferred piece of work promised to nobody, above a function that returns a value and reports success all the same. A static linter can grep for a phrase list or flag a bare `TODO`, and that is worth having; it cannot tell the excuse from the honest note, nor see that the function under it hands back an invented answer instead of refusing.
