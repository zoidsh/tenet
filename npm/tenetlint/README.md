# tenetlint

A command-line linter for the rules you wrote in English: it judges your staged changes against tenets you write in a `tenets.yml`, using TypeSafe jev.

Install it with `npm install -g tenetlint`, or run it with `npx tenetlint`; the command is `tenet`, with `tenetlint` beside it, and the binary for your platform comes from an optional dependency, so there is no install script.

The documentation lives at https://github.com/zoidsh/tenetlint.
